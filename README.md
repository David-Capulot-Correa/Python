# 🐍 Lista de Exercícios em Python

Repositório criado para reunir uma coleção de **exercícios práticos em Python**, desenvolvidos com o objetivo de aprimorar a lógica de programação, a resolução de problemas e os fundamentos da linguagem.

Os exercícios abordam conceitos básicos e intermediários de Python, permitindo evoluir gradualmente desde os primeiros comandos até estruturas mais elaboradas.

---

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como uma forma de **praticar e consolidar conhecimentos em Python**, explorando diferentes conceitos da programação por meio de exercícios práticos.

A lista busca desenvolver principalmente:

* 🧠 Lógica de programação
* 🐍 Fundamentos do Python
* 🔢 Operações matemáticas
* 🔀 Estruturas condicionais
* 🔁 Estruturas de repetição
* 📋 Listas e outras estruturas de dados
* 🔤 Manipulação de strings
* 📦 Funções
* 🗂️ Organização e reutilização de código
* 🛠️ Resolução de problemas

---

## 🎯 Objetivos

* Desenvolver o raciocínio lógico.
* Praticar a sintaxe da linguagem Python.

## 🚀 Como Executar

### 1️⃣ Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2️⃣ Entre na pasta

```bash
cd lista-exercicios-python
```

### 3️⃣ Execute um exercício

```bash
python exercicios/exercicio01.py
```

> Dependendo do sistema, pode ser necessário utilizar `python3` no lugar de `python`.
